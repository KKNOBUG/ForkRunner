# 约束拆分规则

> 适用于任务(a)：当场景对多个字段存在约束时，判定是否拆分为多个输出行；以及范围类约束的边界值拆行规则。

## 一、多约束字段拆分规则

当场景中对**多个字段**存在约束时（无论约束类型是否相同），**不可**将它们全部塞入一行，而必须为**每个被约束的字段单独生成一行**。

> 原因：如果一行中多个字段同时受约束，测试执行时无法区分校验失败是由哪个字段的哪个约束引起的，违反了"一个测试案例只验证一个独立变量"的测试原则。

拆分规则：

1. 仅 1 个字段受约束 → 生成 1 行，直接应用其约束
2. N 个字段受约束 → 生成 N 行，每行**仅 1 个**字段应用其约束条件，**其余受约束字段填入同分区快照值**，非约束字段使用同分区快照值
3. 同一字段路径被多次标记但中文名不同（如 `车贷贷款金（$.bosc）必输、附加费贷款金额（$.bosc）必输`）→ 按出现次数各生成 1 行，分别对应不同的业务校验场景
4. **仅**"直接赋值"（传X）类型的约束 → 无需拆分，多个直接赋值可共存于一行。**其余所有约束类型（必输/不录入、长度限制、格式校验、枚举值、字符约束、数值范围等）——无论是否属于同一个业务场景——均必须拆分，每行仅1个字段应用其约束**

## 二、条件触发联动场景的拆分判定

当场景文本中出现"如果…则…""当…时…""若…那么…""传X,则…"等**"前提→触发"句式**时，**不可**直接套用"多个字段由同一前提触发可共存"的直觉，必须按下表逐项判定：

| 触发后受约束的字段情况 | 是否拆分 | 说明与示例 |
|---|---|---|
| 仅触发 **1个** 字段（任意约束类型） | **不拆分**，1行 | 单一变量，如 `bosservicetype传1,则bosloanamt必输` |
| 触发 **多个** 字段，且触发后的约束**全部为"必输"或"不录入"** | **必须拆分**，每个必输/不录入字段 1 行 | 同一行中多个字段置空无法区分校验失败原因。如 `bosservicetype传3,则F1、F2、F3、F4必输` → **拆4行** |
| 触发 **多个** 字段，触发后的约束**混合了"必输/不录入"与其他类型** | **必须拆分**，每个必输/不录入字段各自 1 行，其他类型约束可与之共存 | 必输/不录入字段优先隔离。如 `A传2时B必输且C长度不超过10` → **拆2行**（行1: B=""+C=合法长度；行2: B=同分区快照值+C=超长） |
| 触发 **多个** 字段，触发后的约束**均非"必输/不录入"且类型互不相同** | **不拆分（唯一豁免）**，1行 | 各字段约束类型不同，联合验证同一条条件依赖规则时可区分。如 `A传1时B格式为身份证且C为枚举值X` |

> **核心结论**：条件触发联动场景中，**只要触发后的约束涉及多个字段的"必输"或"不录入"**（无论全部还是部分），就必须按必输/不录入字段的数量拆分。豁免**仅**适用于触发后各字段约束类型互不相同且**不含任何必输/不录入**的场景。

## 三、常见误判警示

以下模式在场景文本中高频出现，极易被错误合并为一行，实际必须拆分：

| 场景文本模式 | 错误做法 | 典型误判原因 | 正确做法 |
|---|---|---|---|
| `传X,则F1、F2、...、Fn必输` | 1行内全置空 | 误用"条件触发联动豁免" | **拆n行**，每行仅1个字段置空 |
| `XX为Y,不录入F1,F2,...,Fn` | 1行内全置空 | 误用"条件触发联动豁免" | **拆n行**，每行仅1个字段置空 |
| `不录入 XX 相关字段（F1、F2、...、Fn）` | 1行内F1~Fn全置空 | 视为"同一业务规则" | **拆n行**，每行仅1个字段置空 |
| `不录入 F1、F2`（无"相关字段"字样） | 1行内F1、F2全置空 | 视为"同一业务规则" | **拆2行**，每行仅1个字段置空 |
| `F1、F2、...、Fn 必输` | 1行内全置空 | 视为"同一业务规则" | **拆n行**，每行仅1个字段置空 |
| `F1 必输，F2 必输` | 1行内两个全置空 | 视为"同一业务规则" | **拆2行** |

> **统一判断标准**：只要场景中**明确列出多个字段名**，且对它们施加了**置空类约束**（必输/不录入/留空），就必须按字段数拆分——**无论这些约束是否由同一个前提条件触发**。仅有的例外是：(1) 规则4中的"直接赋值"（传X）可共存；(2) 条件触发联动中，触发后的约束全部互不相同且**不含任何必输/不录入**的情况。

## 四、范围类约束拆分规则

当场景中出现**"符合"或"不符合"**关键字修饰数值/长度范围时——

| 关键字 | 含义 | 拆分规则 |
|--------|------|---------|
| **符合**（满足/在范围内） | 字段值应在约束范围内 | 见下方"符合范围"拆分表 |
| **不符合**（不满足/在范围外） | 字段值应违反约束范围以触发校验失败 | 违反路径 = N条 → 拆为 N 行 |

### 4.1 "符合范围"的拆分（边界值 + 中间值）

| 区间类型 | 符合范围 | 生成行数 | 取值明细（中间值先计算再按字段精度表示，不得提前取整或任意取值） |
|---------|---------|---------|---------|
| **开区间** (A, B) | A < x < B | **1** | x=(A+B)/2 |
| **闭区间** [A, B] | A ≤ x ≤ B | **3** | x=A, x=(A+B)/2, x=B |
| **左闭右开** [A, B) | A ≤ x < B | **2** | x=A, x=(A+B)/2 |
| **左开右闭** (A, B] | A < x ≤ B | **2** | x=(A+B)/2, x=B |
| **仅下界** (A, +∞) | x > A | **1** | A + 1个步长 |
| **仅下界** [A, +∞) | x ≥ A | **2** | x=A, x=A+1个步长 |
| **仅上界** (-∞, B) | x < B | **1** | B - 1个步长 |
| **仅上界** (-∞, B] | x ≤ B | **2** | x=B-1个步长, x=B |

### 4.2 "不符合范围"的拆分（违反路径数取决于区间开闭性）

| 区间类型 | 场景原文表述 | 符合范围 | 不符合范围 | 违反路径数 | 违反路径明细 |
|---------|------------|---------|-----------|-----------|-------------|
| **开区间** | `大于A且小于B` | A < x < B | x ≤ A 或 x ≥ B | **4** | x<A, x=A, x=B, x>B |
| **闭区间** | `大于等于A且小于等于B` / `不低于A且不超过B` | A ≤ x ≤ B | x < A 或 x > B | **2** | x<A, x>B |
| **左闭右开** | `大于等于A且小于B` / `不低于A且小于B` | A ≤ x < B | x < A 或 x ≥ B | **3** | x<A, x=B, x>B |
| **左开右闭** | `大于A且小于等于B` / `大于A且不超过B` | A < x ≤ B | x ≤ A 或 x > B | **3** | x<A, x=A, x>B |
| **仅下界** | `大于A` / `大于等于A` | — | x ≤ A（开）/ x < A（闭） | **2** | x<A, x=A（开区间）/ x<A, x=A（闭区间见注） |
| **仅上界** | `小于B` / `小于等于B` | — | x ≥ B（开）/ x > B（闭） | **2** | x=B, x>B（开区间）/ x>B, x=B（闭区间见注） |

> **判定方法**：先看场景原文用的是"大于"还是"大于等于"，确定区间开闭性；再用 De Morgan 定律算出违反条件；违反条件中每个独立分支 = 1 条违反路径 = 1 行。
>
> 注：仅单侧下界时，"等于下界"是否算违反取决于下界是开（>）还是闭（≥）。开的等于下界算违反，闭的等于下界不算违反，但闭的下界外（x < A）和开的下界外（x ≤ A 中 x < A 部分）实际取值逻辑类似，具体按开闭性判定。

### 4.3 每个违反路径的取值原则

| 违反路径 | 取值 |
|---------|------|
| **小于下界**（x < A） | A - 1个合法步长 |
| **等于下界**（x = A） | A 本身（仅当 A 不在符合范围内时才作为违反路径） |
| **等于上界**（x = B） | B 本身（仅当 B 不在符合范围内时才作为违反路径） |
| **大于上界**（x > B） | B + 1个合法步长 |

### 4.4 "合法步长"取值根据字段类型确定

必须根据字段实际业务含义选择对应类型：

| 字段类型 | 判断依据 | 合法步长 | 示例（范围 10000~200000） |
|---------|---------|---------|--------------------------|
| **金额/货币** | 字段路径含 `amt`/`price`/`cap`/`income`/`money`/`amount`，或同分区快照值带小数 | `0.01`（分） | 下界外=9999.99，上界外=200000.01 |
| **整数/数量** | 字段路径含 `term`/`cnt`/`num`/`times`/`age`，或同分区快照值为整数 | `1` | 下界外=9999，上界外=200001 |
| **利率/比率** | 字段路径含 `rat`/`rate`/`prop`/`ratio`，快照值为小数如 `4.1` | `0.01`（或按快照精度） | 下界外=4.09，上界外=24.01 |
| **日期** | 字段路径含 `date`/`day`/`birthday` | `1天` | 下界外=20220606，上界外=20420708 |
| **字符串长度** | 字段路径含 `addr`/`name`/`unit` 等 + 场景约束为长度 | `1个字符` | 下界外=4字符，上界外=21字符 |

> 此规则适用于所有含上下界的约束（数值范围、长度范围、日期范围等），不限于数值字段。

## 五、拆行后的总行数

拆行后的总数不得超过 10000，预计超限时直接失败。
