# 场景描述构建规范

> 适用于任务(b)(c)：提取字段中文名→路径映射，并为每个输出行构建标准化场景描述。

## 一、字段中文名→HEAD/BODY 路径映射（任务b）

从场景文本中识别所有 `中文名（字段路径）` 模式，以及单独的 `中文名` 引用，建立中文名到 HEAD/BODY 分区路径的映射表，用于后续构建【】内的中文标注。

- 场景中已写明完整字段路径（如 `$.customer.name`）→ 直接使用该路径，并按路径推断所属分区（HEAD 或 BODY）
- 场景中只写中文名（如 `客户姓名`）→ 在 `request_snapshot.json` 中按末级字段名查找；HEAD 和 BODY 合并后唯一匹配时使用，多匹配或未匹配时按 `rules/01-场景约束解析规则.md` 第一节处理
- HEAD 与 BODY 中存在同名路径时，必须在场景描述中标注所属分区（如 `姓名（HEAD: $.name）`）

## 二、标准化场景描述格式（任务c）

**必须**严格按照以下格式为每条场景生成场景描述：

```
{原始场景文本（去除末尾换行及空白）} - 【{字段中文名}（{HEAD/BODY 字段路径}）："{值}"，{字段中文名}（{字段路径}）："{值}"】
```

构建规则：

| 规则 | 说明                                          |
|------|---------------------------------------------|
| 连接符 | 场景文字与【】之间用 ` - `（空格+短横+空格）分隔                |
| 【】内字段顺序 | 按场景文本中**出现的先后顺序**排列                         |
| 字段格式 | `中文名（字段路径）："值"`                              |
| 分隔符 | 多个字段之间用 `，`（**中文逗号**）分隔                     |
| 空值 | 值为空字符串时格式为 `中文名（字段路径）：""`                    |
| 范围 | 【】内列出场景文本中**出现的所有字段**及其在本行中的实际值。包括：(1) 直接指定值的字段（"传X"）；(2) 作为约束条件前提的字段（"当A=X时"）；(3) 在等式/公式/比较中作为**引用值**出现的字段（如 `A=B`、`A>B`、`A=B+C` 中的 B、C），即使其值来自同分区快照值。**唯一例外**：仅作背景叙述、不参与任何值判定的字段可省略 |
| 无覆盖时 | 若场景未提及任何 HEAD/BODY 字段，省略 ` - 【...】` 部分，仅保留清理后的原始场景文本 |
| 语言 | **必须使用中文**输出场景描述内容                          |
| 长度 | 场景描述最长 255 个字符；超过时压缩非关键信息，但不得丢失原场景意图、被测字段和目标值。相关字段仍应列出，不得仅按字符数截断 |
| 唯一性 | 范围拆行或同一输入场景产生多行时，在文字中明确边界或被测字段，确保最终描述不重复 |
