# 分析结果 JSON 模板

SDK 最终结构化结果的 `analysis` 字段必须是非空数组。以下展示该字段的值；后端会将此数组保存为 `_analysis_result.json`。每个元素代表最终 Excel 的一行：

```json
[
  {
    "source_index": 0,
    "序号": 1,
    "场景类型": "异常流程",
    "场景描述": "客户资料校验-姓名（name）必输 - 【姓名（$.customer.name）：\"\"】",
    "字段改动": {
      "HEAD": {},
      "BODY": {
        "$.customer.name": ""
      }
    },
    "受约束字段": {"HEAD": [], "BODY": ["$.customer.name"]}
  }
]
```

## 契约

- `source_index` 是输入JSON中该场景的全任务索引；必须覆盖当前批次全部输入，拆行时重复相应索引。`序号`、`场景类型`用于追溯输入场景；拆行时可以重复。
- `场景描述`必填、唯一，最长 255 个字符；超长时压缩非关键信息，保留原场景意图、被测字段、目标值及相关字段明细。
- `字段改动`必须按 HEAD/BODY 分区，只包含本行需要修改的字段路径和值；未改动字段由后端按 `request_snapshot.json` 快照补齐。额外字段不写入 Excel；键顺序不决定 Excel 顺序，最终始终按快照顺序输出。
- `受约束字段`按 HEAD/BODY 分区，各为字段路径数组，用于最终 Excel 黄色高亮；其中不在对应快照分区内的字段会被忽略。
- 字段值只允许字符串、数字、布尔值或 `null`，不得嵌套对象或数组。
- 最多生成 10000 行。

后端逐批校验并写入临时CSV；全部批次通过后输出脚本再转换为Excel。不符合时任务失败，不生成或覆盖最终文件。
